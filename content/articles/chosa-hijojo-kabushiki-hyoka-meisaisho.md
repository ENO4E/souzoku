会社経営者の相続で自社株を評価するときは、国税庁の様式「取引相場のない株式（出資）の評価明細書」を作成して申告書に添付します。第1表の1から第8表まであり、**会社の規模と株主の立場を判定してから、類似業種比準価額と純資産価額を計算し、最後に評価額を確定する**という流れです。ここでは各表の役割を概観します。

## 各表の役割

| 表 | 内容 |
| --- | --- |
| 第1表の1 | 評価上の株主の判定（同族株主か、議決権割合）と会社規模の判定の明細 |
| 第1表の2 | 会社規模（大・中・小）の判定（従業員数・総資産価額・取引金額） |
| 第2表 | 特定の評価会社（株式等保有特定会社・土地保有特定会社・開業後3年未満・比準要素数1など）の判定 |
| 第3表 | 一般の評価会社の株式の価額の計算（原則的評価方式と配当還元方式） |
| 第4表 | 類似業種比準価額の計算（配当・利益・純資産を業種平均と比べる） |
| 第5表 | 1株当たりの純資産価額の計算（資産・負債を相続税評価額に置き換える） |
| 第6表 | 特定の評価会社の株式の価額の計算 |
| 第7表・第8表 | 株式等保有特定会社の株式の価額（S1＋S2方式）の計算 |

## 作成の流れ

1. **第1表の1**：株主名簿から相続後の議決権割合を整理し、同族株主グループに属するか、原則的評価か配当還元方式かを判定する
2. **第1表の2**：直前期末の従業員数・総資産（帳簿価額）・年間取引金額から会社規模を決める。規模によって類似業種比準価額と純資産価額の併用割合（Lの割合）が変わる
3. **第5表**：直前期末の貸借対照表を元に、土地・建物・株式などを相続税評価額に直し、含み益に対する法人税額等相当額（37%）を控除して純資産価額を出す
4. **第2表**：第5表の結果から株式等や土地の保有割合を計算し、特定の評価会社に当たるか判定する
5. **第4表**：直前期・直前々期の配当・利益・簿価純資産と、国税庁が公表する類似業種の株価・比準要素を使って比準価額を計算する
6. **第3表（または第6表）**：規模に応じた方式で1株当たりの評価額を確定し、相続した株数を掛けて第11表に転記する

## 準備する資料

- 直前3期分の決算書・法人税申告書（勘定科目内訳書を含む）
- 株主名簿、定款、登記事項証明書
- 会社が持つ土地・建物の評価資料（路線価、固定資産税評価額）、保有株式の明細

自社株の評価は、役員退職金の支給や含み損のある資産の整理など、**相続開始前の対策によって大きく変わる**財産です。経営者ご自身が各表の意味を知っておくと、生前対策の検討がしやすくなります。[無料相談](/contact/)では現状の株価の概算もお伝えしています。
