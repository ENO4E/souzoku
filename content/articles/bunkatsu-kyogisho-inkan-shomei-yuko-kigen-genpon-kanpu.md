遺産分割協議書には、相続人全員の実印の押印と印鑑証明書の添付が必要です。相続登記、相続税申告、預金の払戻し、証券口座の移管と提出先が多いため、「いつ取った印鑑証明書まで使えるのか」「何通必要か」はよくある疑問です。提出先ごとの扱いを整理します。

## 提出先ごとの有効期限

| 提出先 | 印鑑証明書の有効期限 |
| --- | --- |
| 法務局（相続登記） | 期限の定めなし（古いものでも可） |
| 税務署（相続税申告） | 期限の定めなし |
| 銀行・信用金庫などの預金の払戻し | 3か月以内または6か月以内とする金融機関が多い |
| 証券会社 | 3か月以内または6か月以内が多い |
| 家庭裁判所（調停・審判の関係書類） | 3か月以内とされることが多い |

相続登記と相続税申告は、協議書の作成時点での本人確認という位置づけなので、発行日の制限がありません。一方、金融機関は払戻し時点の本人確認として扱うため、期限を設けています。手続きが長引いて期限を過ぎると、改めて取り直しになります。

## 原本還付の可否

| 提出先 | 原本還付 |
| --- | --- |
| 法務局 | 可（原本還付の申出をし、写しに「原本に相違ない」と記載して提出） |
| 税務署 | 不可（印鑑証明書は原本提出） |
| 金融機関 | 多くは窓口で原本を確認し、写しを取って返却 |

相続税の申告書に添付する印鑑証明書は、写しではなく原本が必要で、返却されません。したがって、最低でも申告用に1通は別に取得しておく必要があります。登記用は還付を受けられるので、金融機関の手続きに回すことができます。

## 何通取るべきか

一般的には、相続人一人につき次の通数が目安です。

- 相続税申告用：1通（還付なし）
- 相続登記用：1通（還付可。金融機関に転用できる）
- 金融機関：原本確認後返却の場合は登記用を転用、原本提出を求められる場合は金融機関ごとに1通

手続きの順序としては、まず相続登記に提出して還付を受け、その後に金融機関を回ると通数を節約できます。ただし金融機関の期限（3か月など）があるため、登記に時間をかけすぎると取り直しになります。

## 段取りの注意点

- 印鑑証明書は本人（または代理人）しか取得できず、海外在住の相続人は署名証明で代用します
- 協議書の押印は印鑑証明書と同じ実印で行います。印影がわずかでも違うと手続きが止まります
- 相続放棄した人の印鑑証明書は不要です（家庭裁判所の相続放棄申述受理通知書の写しを添付）

協議書の内容を固めてから一斉に印鑑証明書を取得し、申告と登記を同じ時期に進めるのが、取り直しを防ぐ最も効率的な進め方です。
