相続税の申告書は「第1表」から「第15表」までの様式で構成されています。ただし、すべての表を使うわけではなく、**多くの相続では第1表・第2表・第9表・第11表・第13表・第15表と、使う控除に応じた表を数枚**加える程度です。作る順番は番号順ではなく、「財産の明細を先に作り、最後に税額を計算する」のが基本です。

## 各表の役割

| 表 | 内容 | 使う人 |
| --- | --- | --- |
| 第1表 | 各相続人の課税価格と税額のまとめ | 全員 |
| 第2表 | 相続税の総額の計算 | 全員 |
| 第4表・第4表の2 | 2割加算、暦年課税分の贈与税額控除 | 該当者 |
| 第5表 | 配偶者の税額軽減 | 配偶者がいる場合 |
| 第6表 | 未成年者控除・障害者控除 | 該当者 |
| 第7表 | 相次相続控除 | 10年以内に前の相続がある場合 |
| 第9表・第10表 | 生命保険金・退職手当金 | 受け取った場合 |
| 第11表 | 相続税がかかる財産の明細 | 全員 |
| 第11・11の2表の付表 | 小規模宅地等の特例 | 特例を使う場合 |
| 第13表 | 債務・葬式費用 | 差し引く場合 |
| 第14表 | 相続開始前の贈与財産、寄附 | 該当者 |
| 第15表 | 財産の種類別価額表（集計） | 全員 |

第3表（農業相続人）、第8表（外国税額控除・納税猶予）、第12表（農地等の納税猶予）は、該当する場合だけ使います。

## 作成の順番

1. **財産の評価を終える**（土地・建物・株式などは評価明細書を先に作成）
2. **第9表・第10表**で生命保険金・退職手当金の非課税額を計算
3. **第11表**に財産を1件ずつ記載（小規模宅地等の特例は付表で減額を計算してから転記）
4. **第13表**に債務・葬式費用、**第14表**に3年（段階的に7年）以内の贈与や寄附を記載
5. **第15表**で財産の種類ごとに集計し、相続人ごとの合計を出す
6. **第1表**に課税価格を転記し、**第2表**で総額を計算
7. **第4〜7表**で加算・控除を計算し、第1表に戻って各人の納付税額を確定

## 間違えやすいポイント

- 第15表の合計と第11表・第13表の合計が一致していない
- 配偶者の税額軽減（第5表）を使うのに、分割が済んでいない財産を含めている
- 贈与税の申告をした財産を第14表に書き忘れ、贈与税額控除も漏れている

各表は連動しているため、一つの数字を直すと複数の表を直すことになります。財産の確定を先に終えてから申告書に入るのが、やり直しを減らすコツです。
