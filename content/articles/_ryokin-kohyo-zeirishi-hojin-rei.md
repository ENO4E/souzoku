相続税申告を依頼する前に料金の目安を知りたいとき、いちばん確実なのは各事務所が公開している料金表を見ることです。この記事では、相続税申告の料金をウェブサイトで公開している税理士法人5つについて、**公式サイトに掲載されている内容をそのまま**まとめました。並びは法人名の五十音順で、順位や優劣を示すものではありません。

| 遺産総額 | 基本報酬（税込） |
|---|---|
| 7,000万円まで | 748,000円 |
| 1億円まで | 880,000円 |
| 1億5,000万円まで | 1,166,000円 |
| 2億円まで | 1,452,000円 |
| 2億5,000万円まで | 1,716,000円 |
| 3億円まで | 1,980,000円 |
| 3億円超 | お見積り |

- 相続人や土地の数による追加費用はかからないと案内しています
- 申告期限まで3か月を切っている場合は、特急料金がかかることがあるとしています
- 遺産総額は、債務や特例・控除を差し引く前のプラスの財産の総額としています

出典：[円満相続税理士法人「料金」](https://osd-souzoku.jp/fee/)

## 辻・本郷税理士法人

- 「相続コミコミプラン」として、一律45万円（税込）・追加料金なしのプランを案内しています
- 対象は、遺産が1億円未満、土地が3つ以内、相続の開始から7か月以内のご依頼です
- プランの対象外の場合の報酬は、遺産総額の1%程度を目安としています

出典：[辻・本郷税理士法人「相続税申告サービス」](https://www.ht-tax.or.jp/sozoku/)

## 料金表を見るときの注意

料金は改定されることがあります。依頼を検討するときは、必ず各法人の公式サイトで最新の料金表を確認し、財産の内容を伝えたうえで見積もりを受け取ってください。

この記事は、相続税申告相談センター（運営：タックス・プラン税理士法人）が、各法人の公式サイトの掲載内容を紹介するために作成したものです。各法人の料金・特徴は掲載内容のとおりに記載しており、当センターによる評価や推奨を含むものではありません。
