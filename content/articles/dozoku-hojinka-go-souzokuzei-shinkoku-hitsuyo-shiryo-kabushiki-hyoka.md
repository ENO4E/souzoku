資産管理会社や不動産を持つ同族会社のオーナーが亡くなると、相続税申告は「個人の財産」と「会社の株式」の二本立てになります。結論から書くと、**株式の評価には会社側の資料が個人の財産以上に必要で、不動産が多い会社ほど評価に時間がかかるため、相続開始から3か月以内に資料集めを始めることが申告期限を守る鍵です**。

## 必要な資料の一覧

| 資料 | 何に使うか |
| --- | --- |
| 直前3期分の決算書・法人税申告書（勘定科目内訳書を含む） | 会社規模の判定、類似業種比準価額の利益・配当・純資産、純資産価額の帳簿価額 |
| 固定資産台帳 | 不動産ごとの帳簿価額と取得日（3年以内取得の時価評価の判定） |
| 不動産の登記事項証明書 | 所有者・持分・地積・床面積の確認 |
| 固定資産税の課税明細書（納税通知書） | 建物の固定資産税評価額、土地の倍率方式の基礎 |
| 賃貸借契約書・入居状況の一覧 | 貸家・貸家建付地の判定、賃貸割合 |
| 土地の無償返還に関する届出書の控え | 社長の土地に会社の建物がある場合の80%評価と借地権20%の計上 |
| 株主名簿・定款・登記簿 | 同族株主の判定、議決権割合、株式数 |
| 役員借入金・役員貸付金の残高、金銭消費貸借契約 | 社長の貸付金（相続財産）または債務の確定 |
| 生命保険の契約内容（会社契約） | 解約返戻金・死亡保険金の資産計上、死亡退職金の原資 |
| 従業員数、直前期の取引金額 | 会社規模の判定 |

個人側の資料（預金・不動産・保険・債務）はこれとは別に必要です。

## 評価に時間がかかる理由

1. **不動産を一件ずつ評価し直す**：純資産価額では会社の土地建物をすべて路線価・固定資産税評価額で評価します。物件が10件あれば、個人の土地10件を評価するのと同じ手間です
2. **3年以内取得の時価**：直近に買った物件は時価の根拠（取得価額、鑑定）を別に用意します
3. **会社規模と特定会社の判定**：[規模の判定](/articles/hyoka-kaisha-kibo-hantei/)に加え、土地保有割合が高いと土地保有特定会社として純資産価額のみになります
4. **直前期末と課税時期のずれ**：原則は直前期末の決算を使いますが、期末から相続までに大きな資産の動きがあれば仮決算を組みます
5. **役員借入金の整理**：社長の会社への[貸付金](/articles/kashitsukekin-yakuin-kariirekin/)は額面で相続財産になり、会社と個人の[お金の混在](/articles/jigyo-kaisha-kojin-okane-mazatteiru-seiri-meigi-tatekae/)があると帳簿と通帳の突き合わせが必要です

これらをまとめた[取引相場のない株式の評価明細書](/articles/chosa-hijojo-kabushiki-hyoka-meisaisho/)を申告書に添付します。

## 申告期限10か月からの逆算

- **〜3か月**：会社の顧問税理士に決算書・台帳・届出の控えを依頼し、個人の財産も一覧化。役員の交代と代表者変更の登記
- **〜5か月**：不動産と株式の評価の概算。納税額の見込みと納税資金（死亡退職金・会社からの自己株式の買取りなど）の検討
- **〜8か月**：遺産分割協議（株式を後継者に集めるか、不動産と株式をどう分けるか）
- **〜10か月**：申告書と評価明細書の提出、納税

株式の評価が終わらないと分割の話に入れないため、評価の遅れがそのまま期限の圧迫になります。当センターでは、会社の資料を受け取った段階で評価の概算をお伝えし、期限から逆算した進め方をご案内しています。相続税申告は基本報酬99,000円（税込・遺産総額4,000万円まで）から、非上場株式の評価は1社110,000円（税込）から、初回のご相談は無料です。
