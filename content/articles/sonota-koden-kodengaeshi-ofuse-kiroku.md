葬儀の前後には、香典を受け取り、お布施を渡し、香典返しを贈るといった金銭のやり取りが集中します。これらは相続税の申告で「引けるもの」「引けないもの」「そもそも財産に入らないもの」に分かれます。領収書が出ない支払いも多いため、**記録の残し方**が実務上の鍵になります。

## 香典と香典返し

香典は、喪主や遺族への贈与と考えられており、社会通念上相当な範囲であれば**相続税も贈与税も所得税もかかりません**。相続財産にも含めません。一方、香典返しは香典に対するお礼であり、香典自体が非課税で相続財産でない以上、**香典返しの費用も葬式費用には含められません**。

香典を葬儀費用の支払いに充てた場合でも、葬式費用の控除額は実際にかかった費用の全額です。香典で賄った分を差し引く必要はありません。

## 葬式費用になるもの・ならないもの

| 項目 | 扱い |
| --- | --- |
| お布施・読経料・戒名料 | 葬式費用になる |
| 葬儀社への支払い（祭壇・棺・式場・火葬） | なる |
| 喪主・遺族が負担した生花・供物 | なる |
| 参列者が供えた生花（遺族の負担でないもの） | 財産にも費用にも影響しない |
| 通夜・葬儀当日の飲食代 | なる（通常の範囲） |
| 香典返し | ならない |
| 初七日・四十九日などの法会の費用 | ならない |
| 墓地・仏壇の購入 | ならない |

葬儀当日に初七日法要を併せて行う場合、葬儀社の請求に一体で含まれていれば区分が難しく、実務では葬儀費用に含めて計上することが多いものの、明細上で明確に法要分と分かれていれば除くのが原則です。

## 領収書が出ない支払いの記録方法

お布施や戒名料は、寺院が領収書を出さないことがほとんどです。それでも葬式費用として控除できますが、申告書に添付する明細として次の記録を残します。

- 支払日
- 支払先（寺院名・住所）
- 金額
- 内容（お布施・戒名料・お車代など）
- 支払った人の氏名

メモ書きやノートで十分ですが、支払いに使った預金の出金記録と金額が合っていると信頼性が高まります。生花や供物についても、葬儀社とは別に花屋へ直接支払った場合は領収書を取っておきます。

## 香典の記録も必要

香典は非課税ですが、税務調査では「葬儀費用をどの資金で支払ったか」を確認するため、香典帳（受け取った香典の一覧）の提示を求められることがあります。葬儀直後の現金の動きを説明するためにも、香典帳と、香典を入金した口座の記録は申告が終わるまで保管しておきましょう。
