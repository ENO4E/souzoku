結論から書くと、**最初の1か月は「死亡届と葬儀 → 年金・健康保険の届出 → 銀行への連絡 → 戸籍集めと財産の把握」の順で進め、相続税がかかりそうかどうかだけは早めに見当をつける**のがいちばん迷いません。期限のある手続きは役所まわりに集中し、相続税の申告は10か月後ですが、相続税がかかるかで「分け方」と「銀行の手続きの進め方」が変わるからです。

## 最初の1か月でやることを順番に

1. **死亡届と火葬許可**（7日以内・市区町村の役所）：葬儀社が代行することがほとんどです。死亡診断書のコピーは複数取っておきます
2. **葬儀・お寺・香典の記録**：領収書と香典帳は捨てないでください。葬儀費用は相続税の計算で財産から引けます
3. **年金と健康保険の届出**（14日以内が目安）：年金は年金事務所、国民健康保険・後期高齢者医療・介護保険は役所です。未支給年金や葬祭費の請求も同じ窓口で聞けます
4. **公共料金・携帯・クレジットカード**：引き落とし口座が止まる前に名義変更か解約を
5. **銀行への連絡**：亡くなったことを伝えると口座は凍結されます。当面の支払いの見通しを立ててから連絡します（[銀行の手続きの順番](/articles/souzoku-ginko-koza-toketsu-tetsuzuki-nani-kara-zandaka-shomei/)）
6. **戸籍集め**：亡くなった方の出生から死亡までの戸籍一式（[戸籍の集め方](/articles/koseki-shushu-koiki-kofu/)）
7. **財産の把握**：通帳、固定資産税の納税通知書、保険証券、証券会社の郵便物を一か所に集めます

## どこで誰に聞くか

| 困りごと | 聞く先 |
| --- | --- |
| 死亡届・国保・介護保険・葬祭費 | 市区町村の役所（大阪市なら区役所） |
| 年金の停止・未支給年金・遺族年金 | 年金事務所 |
| 口座の凍結・払戻し・名義変更 | 各金融機関の相続窓口 |
| 自宅の名義変更（相続登記） | 法務局・司法書士 |
| 相続放棄するかどうか | 家庭裁判所・弁護士（3か月以内） |
| 相続税がかかるか・いくらか・どう分けるか | 相続税を扱う税理士 |

期限の一覧は[相続手続きのスケジュール](/articles/souzoku-tetsuzuki-schedule/)に、公的機関の無料相談と税理士の無料相談の違いは[相続の無料相談はどこでできる？](/articles/souzoku-muryo-soudan-doko-koteki-shigyo-minkan-tsukaiwake/)にまとめています。

## 相続税がかかりそうかを早めに見る理由

相続税は、財産の合計が基礎控除（3,000万円＋600万円×法定相続人の数）を超えるとかかります。相続人が母と子2人なら4,800万円です。大阪市内や北摂の持ち家に預金と保険が加わると、この額を超えるご家庭は珍しくありません。早めに見る理由は3つあります。

- 配偶者の税額軽減や小規模宅地等の特例は「誰が何を相続するか」で使えるかが決まるので、分け方を決める前に知っておく必要がある
- 相続税がかかるなら、銀行の残高証明書を「亡くなった日」の日付で取るなど、手続きの進め方が変わる
- 申告期限（10か月）から逆算すると、財産の確定と遺産分割に使える時間は短い

## 無料相談で一度に段取りできる

相続税申告相談センター（大阪・南森町）の無料相談では、固定資産税の納税通知書と通帳・保険証券をお持ちいただければ、その場で相続税がかかるかと税額の目安をお伝えし、遺産分割の進め方、自宅の名義変更（提携の司法書士）、揉めごとの相談先（提携の弁護士）、不動産の評価と売却の税金まで、窓口ひとつで段取りします。相続税申告は基本報酬99,000円（税込・遺産総額4,000万円まで）〜、遺産分割協議書の作成は55,000円（税込）で、書面添付制度により税務署に指摘されにくい申告を行います。初回面談0円、電話は06-6354-8220（平日9:00〜18:00）、[無料相談のお申込み](/contact/)は24時間受け付けています。税額の見当は[相続税シミュレーション](/simulation/)でも確かめられます。
