結論から書くと、**税理士の相続相談で聞かれるのは「家族構成」「亡くなった日」「財産の種類と場所」「借入」「生前の贈与」「保険」「分け方の希望」「期限」の8項目で、どれも「分からない」と答えて構いません**。質問はすべて「相続税がかかるか」「いくらか」「特例が使えるか」を判断するためのもので、答えを試す場ではありません。

## 聞かれる質問と、なぜ聞くのか

| 質問 | なぜ聞くのか |
|---|---|
| 家族構成（配偶者、子の人数、先に亡くなった子の有無） | 法定相続人の数で基礎控除（3,000万円＋600万円×人数）と保険の非課税枠（500万円×人数）が決まるため |
| 亡くなった日 | 申告期限（10か月）、準確定申告（4か月）、相続放棄（3か月）を逆算するため |
| 財産の種類と場所（自宅・土地・預金・株など） | 評価の方法と、土地の評価の加算（1か所ごと）を見積もるため。「吹田市の自宅と、郵便局と銀行の預金」のような粒度で足ります |
| 借入・未払金・葬儀費用 | 財産から差し引けるため |
| 生前の贈与（毎年の贈与、住宅資金・教育資金の非課税の利用） | 相続開始前の一定期間（3年から7年へ段階的に延長中）の贈与は相続財産に足し戻すため |
| 保険（契約者・被保険者・受取人） | 誰の財産として課税するかが契約の形で変わるため |
| 分け方の希望（誰が自宅に住むか、売るか） | 小規模宅地等の特例（330㎡まで評価額80%減）と配偶者の税額軽減（1億6,000万円まで）で税額が大きく変わるため |
| 期限までの余裕 | 期限まで2か月未満だと特急の加算（125%）になるため。先に伝えておくと費用の見通しがずれません |

## 答えられなくてよいこと

- **正確な金額**：「預金は1,000万円くらい」「土地は40坪くらい」で足ります。正確な数字は残高証明書や課税明細書で後から確定します
- **専門用語**：「路線価」「名義預金」「特別受益」の意味を知っている必要はありません。聞き慣れない言葉が出たら、その場で聞き返してください
- **家族の事情**：仲が悪い、連絡が取れない相続人がいる、再婚している。言いにくいことほど早めに伺えると、分け方と期限の計画が立ちます。守秘義務があります
- **亡くなった方の過去**：若い頃の転居先や昔の借金の有無は、戸籍と郵便物・通帳の引き落としで確かめます（[戸籍の集め方](/articles/koseki-shushu-koiki-kofu/)）

## 面談の前にできる準備

手元にあれば、固定資産税の納税通知書・通帳・保険証券の3点（[税理士に何を渡すか](/articles/souzokuzei-shinkoku-zeirishi-ni-nani-wo-watasu/)）。なくても相談はできます。家族構成を紙に書いておくと、最初の5分が短くなります。来所は大阪市北区東天満の事務所（南森町駅・大阪天満宮駅すぐ、梅田から谷町線で1駅）、オンライン、大阪府・兵庫県（阪神間・神戸）・京都のご自宅への訪問から選べます。

## 無料相談で一度に片づく

8項目を伺えば、相続税の判定・税額の目安・申告費用の総額・次に集める書類がその場で決まります。当センターの無料相談は、遺産分割の進め方・相続登記や名義変更（提携の司法書士）・揉めごと（提携の弁護士）・不動産の評価と売却の税金まで窓口ひとつで段取りします。相続税申告は基本報酬99,000円（税込・遺産総額4,000万円まで）〜、遺産分割協議書の作成は55,000円（税込）。書面添付制度で税務署に指摘されにくい申告を行います。[無料相談のお申込み](/contact/)はフォーム（24時間）か電話（06-6354-8220、平日9:00〜18:00）で、税額の目安は[相続税シミュレーション](/simulation/)でも確かめられます。
