相続税を金融機関の窓口で納めるときは、専用の**納付書（領収済通知書）**を使います。所得税のように申告書に同封されて届くものではなく、**税務署で入手し、相続人ごとに1枚ずつ**作ります。書き方を間違えると納付の処理が遅れたり、別の相続人の税額に充当されたりするため、記入のルールを確認しておきましょう。

## 納付書の入手方法

- 被相続人の住所地を管轄する税務署の窓口でもらう（相続人の人数分。予備を含めて数枚）
- 相続税の納付書は金融機関には置いていないことが多い
- 税理士に申告を依頼している場合は、税理士が用意するのが一般的
- e-Taxで申告する場合は、納付書を使わずダイレクト納付やインターネットバンキングで納めることもできる

## 記入項目と書き方

| 欄 | 書く内容 |
| --- | --- |
| 年度 | 納付する日の属する会計年度（4月〜翌年3月）。例：2026年6月に納めるなら「08」（令和8年度） |
| 税目番号・税目 | 相続税の税目番号「050」、税目「相続税」 |
| 税務署名・署番号 | 被相続人の住所地を管轄する税務署（相続人の住所地ではない） |
| 本税 | 申告書第1表の「申告納税額」の金額 |
| 合計額 | 本税と同じ額（加算税・延滞税がある場合は合算）。先頭に「¥」を付ける |
| 納期等の区分 | 相続開始年月日（被相続人が亡くなった日）を「自」欄に記載 |
| 申告区分 | 「期限内」「修正申告」などに印を付ける様式では該当欄を選ぶ |
| 住所・氏名 | 納付する相続人の住所・氏名を書き、その上または横に「被相続人 ○○○○」と併記する |

**氏名欄に被相続人の名前だけを書く**、**相続人全員の税額を合計して1枚で納める**のは誤りです。相続税は相続人ごとに納税義務があるため、誰の税額をいくら納めたかが納付書で分かる必要があります。

## 納付の手順

1. 相続人ごとに納付書を作成し、金額を申告書第1表と突き合わせる
2. 金融機関（銀行・信用金庫・郵便局）の窓口で納付する。ATMやネットバンキングでは納付書を使えない
3. 領収証書（納付書の右端）を受け取り、申告書控えと一緒に保管する

## 納付書を使わない方法

クレジットカード納付（国税の専用サイトから。納付額1,000万円未満、手数料あり）、コンビニ納付（30万円以下、QRコードを税務署で発行）、ダイレクト納付（e-Tax利用者）、スマホアプリ納付（30万円以下）があります。これらは納付書の代わりに納付情報を入力する方式で、相続人ごとに手続きする点は同じです。

納付の記録は、二次相続の相次相続控除の計算や、相続人間の精算で必要になります。領収証書は申告書と同じ期間保管してください。
