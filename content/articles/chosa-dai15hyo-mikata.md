第15表「相続財産の種類別価額表」は、第11表・第13表・第14表の内容を**財産の種類ごと・相続人ごとに集計した一覧表**です。申告書の控えを後から見返すとき、この1枚を見れば「どの財産がいくらあり、誰がどれだけ取得したか」が分かります。二次相続の検討や相続後の売却のときにも、まずここを確認します。

## 各欄の構成

縦に財産の種類、横に「各人の合計」と相続人ごとの欄が並びます。主な行は次のとおりです。

| 行 | 内容 | 元になる表 |
| --- | --- | --- |
| 土地（田・畑・宅地・山林・その他） | 地目別の価額 | 第11表 |
| 家屋・構築物 | 建物の価額 | 第11表 |
| 事業用財産 | 機械・商品・売掛金など | 第11表 |
| 有価証券 | 特定同族会社の株式、上場株式、公社債など | 第11表 |
| 現金・預貯金等 | 現金と預貯金 | 第11表 |
| 家庭用財産 | 家具・家電など | 第11表 |
| その他の財産 | 生命保険金・退職手当金・立木・その他 | 第9表・第10表・第11表 |
| 合計（課税価格の計算の基礎） | 財産の総額 | |
| 債務・葬式費用 | 差し引く額 | 第13表 |
| 純資産価額 | 財産合計－債務等 | |
| 純資産価額に加算される暦年課税分の贈与財産価額 | 持ち戻し分 | 第14表 |
| 課税価格 | 第1表に転記 | |

「小規模宅地等の特例」を使った土地は、減額後の価額で土地の行に入っています。特例前の価額を知りたいときは付表を見ます。

## 税務署が第15表で見ている点

第15表は税務署にとっても申告内容の全体像をつかむ表です。一般的に、次のような観点で見られています。

- **財産構成のバランス**：不動産に比べて現金・預貯金が極端に少ないと、生前の引き出しや名義預金の有無を確認したくなる
- **有価証券・その他の財産の欄**：証券会社の支払調書や保険金の支払調書と照合しやすい
- **債務の大きさ**：借入金に見合う財産（借入で買った不動産など）が計上されているか

## 控えを読むときの着眼点

1. 課税価格の合計から基礎控除を引いた額が、第2表の「課税遺産総額」と一致しているか
2. 配偶者の取得分が、配偶者の税額軽減の計算（第5表）と合っているか
3. 有価証券・預貯金の額が、残高証明書の合計と一致しているか

第15表は電卓で検算しやすい表でもあります。数字が合わないときは、第11表の記載漏れや二重計上を疑ってみてください。
