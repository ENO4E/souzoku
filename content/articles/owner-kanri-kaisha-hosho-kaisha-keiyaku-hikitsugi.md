賃貸オーナーが亡くなった直後、相続人がまず困るのは「家賃はどこに振り込まれるのか」「管理会社に何を言えばいいのか」です。結論から書くと、**賃貸借契約も管理契約も、死亡で終わらず相続人に引き継がれます。必要なのは、各契約の相手に連絡して、受け皿と名義を順番に変えていくこと**です。

## 亡くなった直後（1〜2週間）

1. **管理会社に死亡の連絡**：当面の連絡窓口になる相続人を伝える。家賃の送金先口座（亡くなった方の口座）が凍結されると送金が止まるので、相続人代表の口座への変更を相談する
2. **家賃の受け皿**：遺産分割が終わるまでの家賃は[法定相続分で各相続人のもの](/articles/fudosan-bunkatsu-mae-yachin-dare-no-mono/)です。実務では、相続人代表の口座で預かり、分割後に精算する形が多い。預かった家賃の記録を残す
3. **サブリース会社**：借上げ会社にも死亡の連絡。[サブリース契約](/articles/owner-sublease-ikkatsu-kariage-hyoka-souzoku/)の賃料の振込先を変更
4. **緊急の修繕・入居者対応**：管理会社に、相続人の了承なしで対応できる範囲（少額修繕）を決めておく

## 遺産分割まで（〜10か月）

- **入居者への通知**：貸主が亡くなったことと、家賃は従来どおり（または変更後の口座へ）払うこと、敷金は新しい貸主が引き継ぐことを文書で通知。[承継の手続き](/articles/fudosan-chintai-apart-shoukei-tetsuzuki/)の記事も参考に
- **家賃保証会社**：保証契約は入居者と保証会社の契約で、貸主が変わっても原則続きますが、貸主の名義変更の届出を求められることがあります
- **火災保険**：契約者が亡くなった方の場合、相続人への[名義変更](/articles/fudosan-kasai-hoken-jishin-hoken-meigi-henko/)。空白期間を作らない
- **固定資産税**：市区町村に[相続人代表者指定届](/articles/sonota-shibogo-nozei-tsuchisho-koteishisanzei-jidoshazei/)を出し、納税通知の宛先を決める
- **金融機関（借入）**：アパートローンの返済口座が凍結される前に連絡。返済を続けられる口座に変更し、相続後の債務引受の相談をする
- **準確定申告**：4か月以内。[賃貸オーナーの準確定申告](/articles/owner-chintai-owner-junkakutei-genka-shokyaku-koteishisanzei/)の記事参照

## 遺産分割後

| 相手 | 手続き |
|---|---|
| 法務局 | 相続登記（取得者名義へ）。[相続登記の必要書類](/articles/fudosan-souzoku-touki-hitsuyou-shorui-menzei/) |
| 管理会社・サブリース会社 | 契約者の名義変更。振込先を取得者の口座に |
| 入居者 | 貸主変更の通知（登記完了後に改めて） |
| 金融機関 | 債務引受の契約（取得者が借入を引き継ぐ） |
| 保険会社 | 火災保険の契約者変更 |
| 税務署 | 取得者の青色申告承認申請・開業届（相続による不動産所得の開始） |
| 消費税（店舗・事務所の賃貸がある場合） | 課税事業者の判定、インボイス登録 |

## 相続税申告のために管理会社からもらう資料

- 相続開始時点の入居状況一覧（各室の契約開始日・家賃・敷金・空室の募集開始日）
- 死亡月の送金明細（[未収家賃・前受家賃](/articles/owner-mishu-yachin-maeuke-yachin-souzoku-zaisan/)の振り分けに使う）
- 預り敷金の残高、管理費・修繕の未払金
