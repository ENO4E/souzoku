「不動産会社から『すぐ買い取ります』と言われた。仲介で売るのとどちらがいい？」。結論から書くと、**買取は早くて手間が少ない代わりに価格は仲介より低いことが多く、税金の計算方法はどちらも同じです。相続税の納付期限や取得費加算の期限に間に合うかどうかで、どちらを選ぶかが決まります**。

## 買取と仲介の違い

| | 買取（不動産会社が買主） | 仲介（一般の買主を探す） |
|---|---|---|
| 価格 | 相場より低いことが多い（会社が再販するための利益と改修費を差し引く） | 相場に近い価格で売れる可能性がある |
| 期間 | 数週間〜1か月程度で決済できることが多い | 買主が見つかるまで数か月。古い家や立地によっては1年以上 |
| 仲介手数料 | 原則かからない | 売買価格の3%＋6万円（税別）が上限 |
| 契約不適合責任 | 免除される契約が一般的 | 売主が一定期間負う。相続した家は中の状態を知らないことが多く、後から修補や減額を求められるおそれ |
| 残置物・解体 | そのまま引き渡せることが多い | 片付けや解体を売主が行うことが多い |
| 近所への配慮 | 売り出し広告が出ない | 内覧や広告がある |

## 税金はどちらも同じ

売却額から取得費と譲渡費用を引いた譲渡所得に、長期なら20.315%、短期なら39.63%がかかります。買取だから税金が安くなることも高くなることもありません。違いは、買取では仲介手数料という譲渡費用がない一方、売却額そのものが低くなる点です。

例えば仲介で3,000万円（仲介手数料約106万円）、買取で2,500万円（手数料なし）の場合、取得費が5%なら、手取りは仲介が約2,894万円−税額、買取が2,500万円−税額です。譲渡所得は仲介のほうが大きく税金も増えますが、税引き後の手取りでも仲介が上回ります。買取が有利になるのは、価格差が小さいときか、時間を優先したいときです。空き家特例や取得費加算は、買取でも仲介でも同じ要件で使えます。

## 納税の期限から逆算する

相続税の納付期限は相続開始を知った日の翌日から10か月です。売却代金で納める予定なら、申告期限までに決済が必要で、仲介で買主が見つからなければ間に合いません。延納（利子税がかかる）や物納（要件が厳しく、換価しにくい土地は認められにくい）もありますが、買取で確実に期限内に現金化するほうが総額で有利なこともあります。

ただし、小規模宅地等の特例を使う土地は[申告期限まで保有する要件](/articles/tokurei-shokibo-souzoku-go-baikyaku-torikowashi/)があるため、申告期限前に売るのは別の土地からです。複数の土地があるなら、どの土地から売るかを先に決めます。納税に余裕があれば、[3年10か月の取得費加算](/articles/shutokuhi-kasan-tokurei/)の期限内で仲介に時間をかける選択もできます。

## 選び方の目安

1. 相続税の納税を売却代金に頼るなら、申告期限までの残り日数で判断する。残り3か月を切っていれば買取が現実的
2. 時間に余裕があり、立地が良ければ仲介。古い家の中身を把握していないなら、契約不適合責任の免除を買取の価値として見る
3. どちらでも、相続登記を済ませておく。[売却前の登記の流れ](/articles/fudosan-baikyaku-mae-touki-nagare/)参照
4. 買取の提示額が仲介の査定より2割以上低いなら、仲介に出してから買取に切り替える「買取保証付き仲介」も選択肢

当センターは不動産の売買を仲介する立場ではなく、相続税申告とあわせて、買取・仲介それぞれの場合の譲渡所得と手取りを試算し、売却後の確定申告までお受けしています。相続税申告は基本報酬99,000円（税込・遺産総額4,000万円まで）から、初回相談は無料です。
