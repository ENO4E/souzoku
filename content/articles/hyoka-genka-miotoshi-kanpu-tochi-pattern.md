相続税の申告を終えた後に「土地の評価で使える減額を使っていなかった」と気づくことがあります。結論から書くと、**申告期限から5年以内なら更正の請求で土地の評価をやり直し、払いすぎた相続税の還付を受けられます**。土地の評価は税理士によって差が出やすく、見直しで還付になる例は少なくありません。ここでは土地の見直しに絞って、見落としが多いパターンと手順を説明します。

## 見落としが多いパターン

| パターン | 見直しのポイント |
| --- | --- |
| 不整形地 | 想定整形地の取り方が不利、かげ地割合の計算漏れ（[不整形地補正](/articles/hyoka-fuseikeichi-hosei-kagechi/)） |
| 無道路地・接道義務違反 | 通路開設費用の控除が未適用 |
| 高圧線下 | 地役権による30%・50%の控除が未適用（登記や契約書の確認漏れ） |
| がけ地・傾斜地 | がけ地補正率、土砂災害特別警戒区域の補正、造成費の控除 |
| 道路との高低差・騒音・忌み施設 | 利用価値が著しく低下している宅地の10%控除 |
| 区画整理中の土地 | 仮換地で評価していない、造成中の95%が未適用 |
| 地積規模の大きな宅地 | 500㎡以上（三大都市圏）の規模格差補正が未適用（[地積規模の大きな宅地](/articles/chiseki-kibo-ookina-takuchi/)） |
| セットバック・私道 | セットバック部分の70%控除、私道の30%評価や評価ゼロ |
| 都市計画道路の予定地 | 予定地部分の補正率が未適用 |
| 評価単位 | 自宅と貸家の敷地を一体で評価している、複数の筆を分けて評価している |
| 間口狭小・奥行長大 | 補正率の掛け忘れ |

申告書の控えにある土地評価明細書を見ると、どの補正が使われたかが分かります。補正率の欄が「1.00」ばかりで、現地の状況と合っていないときは見直しの余地があります。

## 見直しの手順

1. 申告書の控え（第11表・土地評価明細書）と、路線価図・公図・測量図をそろえる
2. [現地調査](/articles/hyoka-genchi-chosa-miru-point/)と[役所調査](/articles/hyoka-yakusho-chosa-miru-point/)を行い、上の表の事情がないかを確かめる
3. 評価をやり直し、当初の評価額との差と、還付になる税額を試算する
4. 差が小さければ請求の手間と見合うか判断する

## 更正の請求の流れ

更正の請求は、相続人ごとに税務署へ更正の請求書を提出して行います。やり直した土地評価明細書、現地写真、役所で取った資料など、減額の根拠を添付します。税務署が内容を審査し、認められれば減額更正の通知と還付が行われます。審査には数か月かかることが一般的です。手続きの詳細は[更正の請求の手続き](/articles/chosa-kosei-no-seikyu-tetsuzuki-shosai/)、還付になる他のケースは[相続税を払いすぎたときの更正の請求](/articles/kousei-seikyu-kanpu/)で解説しています。

## 注意点

- 期限は「申告期限から5年」です。相続開始から5年ではないので、期限後申告をした場合は申告期限を基準に数えます
- 土地の評価額が下がると、相続人全員の税額が変わります。一人だけが請求すると他の相続人との整合が問題になるため、全員で足並みをそろえるのが原則です
- 根拠が弱い減額は認められず、一部だけ認められることもあります。税務署から資料の追加や現地確認を求められることもあります
- 評価減を適用した結果、小規模宅地等の特例の選択を変えたほうが有利になる場合でも、特例の選択替えは原則としてできません

申告書の控えがあれば、見直しの余地があるかを確認できます。当センターでは、現地と役所の調査をしたうえで評価減を検討し、更正の請求でも書面添付で根拠を示します。土地の評価は1か所110,000円（税込）から、初回相談は無料で承ります。
