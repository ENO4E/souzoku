「申告書に書かなければ分からないだろう」という考えは、相続税では通用しません。税務署には**被相続人の生前の所得や財産、相続人への資金の流れを示す情報が、複数の経路で集まる仕組み**があります。どの情報がどこから届くのかを知れば、申告の段階で何を漏らしてはいけないかがはっきりします。

## 税務署が持っている主な情報

| 情報源 | 内容 |
| --- | --- |
| KSK（国税総合管理システム） | 過去の所得税・贈与税の申告、財産債務調書、国外財産調書などを納税者ごとに管理 |
| 市区町村からの死亡の通知 | 相続の発生と固定資産の保有状況。「相続についてのお尋ね」を送る基礎になる |
| 法定調書（支払調書） | 生命保険金・死亡退職金の支払調書、株式の配当・譲渡の支払調書、報酬の支払調書など |
| 不動産登記の情報 | 法務局からの通知で、所有権移転（購入・売却・相続・贈与）を把握。不動産の取得資金についての「お尋ね」の根拠 |
| 国外送金等調書 | 100万円を超える海外への送金・海外からの受金を金融機関が提出 |
| 国外財産調書・財産債務調書 | 一定額以上の資産を持つ人が自ら提出。提出の有無が加算税の増減に影響 |
| CRS（共通報告基準）情報 | 海外の金融機関にある口座の残高・利子などを各国の税務当局が自動で交換 |
| 金融機関への照会 | 税務署が必要に応じて被相続人・家族の取引履歴を直接取り寄せる |

## 申告内容との照合のされ方

1. 死亡の通知を受けた段階で、KSK上の所得・財産情報から**相続税がかかりそうな人**を選び、お尋ねや申告の有無を確認する
2. 提出された申告書を、**支払調書（保険金・退職金・株式）**と突き合わせ、計上漏れがないか機械的に確認する
3. 生前の所得（給与・年金・不動産所得・退職金）の累計から推定される資産と、申告された財産を比べる
4. 不動産の売却代金、満期保険金、退職金の行き先を通帳で追い、家族への移転がないか見る
5. 海外送金や国外財産調書の情報から、海外資産の計上漏れを確認する

## 申告のときに意識すべきこと

- 生命保険金・死亡退職金は、**金額が支払調書で税務署に届いている**前提で、受取人・金額を正確に書く
- 過去に売却した不動産の代金が「どこに行ったか」を説明できるようにしておく
- 海外に口座や不動産があれば、少額でも申告書に記載する
- 相続人への生前の資金移転は、贈与税の申告の有無と合わせて整理する

税務署の情報は年々精度が上がっています。「把握されていない財産を省く」のではなく、**税務署の情報と申告書が一致する状態**を作ることが、調査を短く終わらせる一番の方法です。
