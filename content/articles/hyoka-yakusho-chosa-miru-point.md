土地の減額要因のうち、建築制限や道路の種類、埋蔵文化財といった事情は現地を見ても分かりません。結論から書くと、**役所調査では「都市計画課」「建築指導課」「道路課」「文化財保護課」「法務局」の5か所を回り、それぞれで決まった項目を確認して資料を取ることで、評価減の根拠がそろいます**。多くの市区町村は図面をインターネットで公開しているので、事前に調べてから窓口で確認すると効率的です。

## 都市計画課

| 確認する項目 | 評価への影響 |
| --- | --- |
| 用途地域・容積率・建ぺい率 | 容積率が土地の中で変わる場合の減額（[用途地域が2つにまたがる土地](/articles/hyoka-yoto-chiiki-matagaru-tochi/)） |
| 都市計画道路の予定地 | 予定地部分の補正率による減額（[都市計画道路予定地](/articles/hyoka-toshikeikaku-doro-yoteichi/)） |
| 市街化区域・市街化調整区域 | 調整区域の雑種地のしんしゃく割合 |
| 高度地区・風致地区・景観地区・地区計画 | 原則は路線価に織り込み済み。特有の制限は個別に検討 |
| 土地区画整理事業の施行地区 | 仮換地での評価 |
| 生産緑地の指定 | 生産緑地の減額 |

都市計画図の写しと、用途地域の境界線が「道路境界から何m」かの回答を控えます。

## 建築指導課・道路課

建築指導課では次の点を確認します。

1. **道路種別**：接している道路が建築基準法42条のどの道路か（公道・2項道路・位置指定道路・道路でない通路）。指定道路図と指定道路調書を取得します
2. **接道義務**：間口2m以上で接しているか。満たさなければ[無道路地](/articles/hyoka-mudorochi-hyoka-tejun/)、43条2項の許可の見込みも聞きます
3. **セットバック**：2項道路なら中心線からの後退距離と、片側後退（がけ・水路側）の有無
4. **建築計画概要書**：既存の建物の建築確認の記録。接道や敷地面積の扱いが分かります

道路課では次の点を確認します。

- 道路台帳で公道の認定の有無と幅員、道路境界（官民境界）の確定状況を確認します
- 道路幅員は容積率（前面道路の幅員による制限）にも関わります
- 水路・里道（法定外公共物）の管理者と占用許可の扱いは、河川課や管財課が担当していることがあります

## 文化財保護課（教育委員会）

- 遺跡地図で周知の[埋蔵文化財包蔵地](/articles/hyoka-maizo-bunkazai-hozo-chi-hakkutsu/)に入っているかを確認します
- 周辺での試掘・本発掘の実績、建築時に調査が必要になる見込み、費用の目安を聞きます
- 伝統的建造物群保存地区なら、建物が伝統的建造物に特定されているかを確認します

## 法務局とその他

| 取得する資料 | 用途 |
| --- | --- |
| 登記事項証明書（土地・建物） | 所有者・持分・地目・地積、乙区の地役権（高圧線）・地上権 |
| 公図 | 筆の位置関係、私道・水路・里道の有無、無道路地の判定 |
| 地積測量図 | 間口・奥行・形状の計測、不整形地補正の想定整形地 |
| 建物図面・各階平面図 | 建物の配置と評価単位の判定 |

地積測量図が古い、またはない土地では、現況との違いを現地で確かめます。

役所以外でも、次の資料を集めます。

- 市区町村の資産税課で名寄帳・固定資産評価証明書を取り、私道や山林など納税通知書に出ない土地を洗い出します
- 税務署で路線価図・評価倍率表を確認し、路線価が付いていない道路は特定路線価の要否を検討します
- 都道府県の指定図で土砂災害特別警戒区域の該当を確認します

役所調査の結果は、[現地調査](/articles/hyoka-genchi-chosa-miru-point/)の記録と合わせて土地評価明細書の根拠資料にし、書面添付で税務署に示します。当センターの相続税申告では、現地と役所の調査をしたうえで評価減を検討し、根拠を書面添付で説明します。土地の評価は1か所110,000円（税込）からで、初回相談は無料です。
