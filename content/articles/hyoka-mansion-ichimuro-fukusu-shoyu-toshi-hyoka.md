区分マンションを何室も持つ投資家の相続は、室数の分だけ計算と特例の設計が重なります。結論から書くと、**評価は1室ごとに「敷地権＋建物」を出して区分所有補正を掛け、貸している室は貸家・貸家建付地で減額し、小規模宅地等の特例は貸付事業用200㎡の枠を全室の敷地持分の合計面積で使います**。

## 1室ごとの評価の手順

1. **敷地権**：マンションの敷地全体を路線価×補正率×地積で評価し、登記事項証明書の敷地権割合を掛けます
2. **建物**：その室の固定資産税評価額（課税明細書の専有部分の価格）
3. **区分所有補正**：2024年1月1日以後の相続では、築年数・総階数・所在階・敷地持分狭小度から評価乖離率を計算し、評価水準が0.6未満なら「評価乖離率×0.6」を敷地権と建物の両方に掛けます。計算の手順は[分譲マンションの相続税評価（2024年〜）](/articles/hyoka-kubun-shoyu-mansion-2024-keisan/)、改正の背景は[タワーマンション評価の改正](/articles/fudosan-tower-mansion-hyouka-2024-kaisei/)を参照してください
4. **貸家の減額**：貸している室は、建物を30%減、敷地権を貸家建付地（借地権割合×30%の減）で評価します

例：敷地権の評価（補正前）1,000万円、建物の固定資産税評価額500万円、区分所有補正率1.5、借地権割合60%、賃貸中
敷地権＝1,000万円×1.5×（1−0.6×0.3）＝1,230万円
建物＝500万円×1.5×（1−0.3）＝525万円
合計＝1,755万円

区分所有補正は室ごとに計算するので、同じマンションでも高層階と低層階、広い室と狭い室で補正率が違います。相続開始日に空室だった室は貸家の減額ができないのが原則です。なお、区分所有補正は区分所有登記された1室が対象で、一棟全部を所有している場合には適用されません。

## 小規模宅地等の特例は200㎡を全室で分ける

貸している室の敷地権は貸付事業用宅地等として200㎡まで50%減額できます。各室の面積は「敷地全体の地積×敷地権割合」で、全室の合計が200㎡を超えれば、1㎡あたりの減額が大きい室から順に枠を使います。敷地権の持分面積の出し方は[分譲マンションの敷地権と小規模宅地等の特例](/articles/tokurei-shokibo-kubun-shoyu-mansion-shikichiken/)に書いています。

注意点は、相続開始前3年以内に貸し始めた室は原則として特例の対象外になることです。ただし、亡くなった方が事業的規模（おおむね5棟10室）で3年を超えて貸付業を続けていれば、新しく買った室も対象になります。自宅の敷地（居住用330㎡）と併用する場合は限度面積の調整計算が入ります。

## 管理費・修繕積立金の扱い

| 項目 | 扱い |
| --- | --- |
| 亡くなった日までの未払いの管理費・修繕積立金 | 債務控除 |
| 日割りで前払いした管理費 | 返還されないものは財産に計上しない |
| 管理組合に積み立てた修繕積立金の累計 | 管理組合の財産で返還請求権がないため、相続財産に計上しないのが実務 |
| 入居者から預かった敷金 | 債務控除（返還義務がある） |
| 未収の家賃 | 財産に計上 |

滞納していた管理費を相続人が引き継ぐ扱いは[管理費の滞納と修繕積立金](/articles/fudosan-mansion-kanrihi-tainou-shuzen-tsumitatekin/)にまとめています。室数が多いと残高確認に時間がかかるので、早めに管理会社へ連絡し、室ごとの登記事項証明書・課税明細書・賃貸借契約書と青色申告決算書をそろえます。

当センターでは、複数室の区分所有補正と特例の枠の配分を一覧表にして税額で比べてお見せしています。相続税申告は基本報酬99,000円（税込・遺産総額4,000万円まで）から、土地の評価は1か所110,000円（税込）から、初回相談は無料です。
