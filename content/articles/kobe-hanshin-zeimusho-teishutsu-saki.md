結論から書くと、**相続税の申告書は、相続人の住所ではなく、亡くなった方の最後の住所地を管轄する税務署に提出します。神戸市は区ごとに管轄が分かれ、阪神間の市は市ごとに決まっています。** 大阪や東京に住む相続人が実家の相続を進める場合でも、提出先は神戸や西宮の税務署で、依頼する税理士がどこの事務所でも変わりません。

## 神戸市の区ごとの管轄

| 最後の住所地 | 提出先 |
| --- | --- |
| 神戸市中央区 | 神戸税務署 |
| 神戸市灘区 | 灘税務署 |
| 神戸市東灘区 | 芦屋税務署 |
| 神戸市兵庫区・北区 | 兵庫税務署 |
| 神戸市長田区 | 長田税務署 |
| 神戸市須磨区・垂水区 | 須磨税務署 |
| 神戸市西区 | 明石税務署 |

東灘区が芦屋税務署、西区が明石税務署と、区名と署名が一致しない区があるので注意してください。

## 阪神間の市の管轄

| 最後の住所地 | 提出先 |
| --- | --- |
| 芦屋市 | 芦屋税務署 |
| 西宮市・宝塚市 | 西宮税務署 |
| 尼崎市 | 尼崎税務署 |
| 伊丹市・川西市 | 伊丹税務署 |
| 三田市 | 兵庫税務署 |

宝塚市には税務署が無く西宮税務署、三田市は神戸市兵庫区にある兵庫税務署が管轄です。所在地や受付時間は変わることがあるので、来署の前に国税庁サイトの「税務署の所在地・案内」で確かめてください。署ごとの所在地と管轄は[税務署一覧](/zeimusho/)にまとめています。

## 「最後の住所地」の決まり方と、大阪の税理士に頼む場合

住民票の住所が原則です。老人ホームに入って住民票も移していれば施設の所在地、病院に入院していただけなら自宅の住所です。父が神戸市東灘区の自宅、長男が大阪市北区に住んでいる例なら、提出先は芦屋税務署で、長男の住所は関係ありません。相続人が複数いても申告書は1通にまとめて出すのが一般的で、別々に出すこともできます。税務署から「相続についてのお尋ね」が届くのもこの署からです。[提出先の決まり方の詳細](/articles/souzokuzei-doko-no-zeimusho/)

税理士はどの税務署にも申告書を出せるため、神戸や阪神間の相続を大阪の事務所に依頼しても提出先は変わりません。電子申告（e-Tax）なら来署も不要です。当センター（大阪市北区・南森町）は神戸市内と阪神間のご自宅への訪問、オンライン面談、資料の郵送で申告を進めています。阪急・阪神・JRで大阪まで30分前後の地域なので、来所いただく方も多くいらっしゃいます。[神戸・阪神間から大阪の税理士に頼む流れ](/articles/kobe-hanshin-kara-osaka-zeirishi-irai/)・[遠方・オンラインでの依頼](/articles/enpou-online-de-shinkoku-irai/)

## まとめ

提出先は亡くなった方の最後の住所地で決まり、神戸市は区ごと、阪神間は市ごとに管轄が分かれます。申告の期限は相続開始を知った日の翌日から10か月です。区・市ごとの財産の特徴は[神戸市の相続税申告](/area/kobe/)のページからたどれます。税額の目安は[相続税シミュレーション](/simulation/)で確かめてください。相続税申告相談センター（大阪・南森町）は基本報酬99,000円（税込・遺産総額4,000万円まで）〜、初回相談は無料です。
