倍率地域の土地や農地・山林を相続したとき、最初に開くのが国税庁の「評価倍率表」です。結論から書くと、**宅地の列の数字は固定資産税評価額に掛ける倍率、田・畑・山林の列の「比準」「周比準」「中」「純」はどの評価方法を使うかの指示で、市街化区域の農地は「比準」＝宅地並みの評価になります**。

## 表の列の並び

倍率表は市区町村ごとに次の列で構成されています。

| 列 | 意味 |
| --- | --- |
| 町（丁目）又は大字名 | 土地の所在。地番ではなく町名で探す |
| 適用地域名 | 「全域」「市街化区域」「〇〇以北」など、町の中で倍率が分かれる範囲 |
| 借地権割合 | 貸宅地・借地権の評価に使う割合 |
| 宅地 | 「路線」なら路線価地域。数字なら倍率 |
| 田・畑 | 農地の倍率または評価区分の記号 |
| 山林・原野 | 山林・原野の倍率または記号 |

宅地の列が「路線」なら路線価図に進みます（[路線価地域と倍率地域の違い](/articles/hyoka-rosenka-chiiki-bairitsu-chiiki-chigai/)）。「1.1」なら固定資産税評価額1,000万円の宅地は1,100万円です。

## 田・畑の記号の意味

農地は純農地・中間農地・市街地周辺農地・市街地農地の4区分で評価方法が変わり、倍率表の記号がその区分を示します。

- **純**（例：純 8.5）：純農地。固定資産税評価額×倍率
- **中**（例：中 16）：中間農地。固定資産税評価額×倍率
- **周比準**：市街地周辺農地。宅地比準方式で計算した価額の80%
- **比準**（または市比準）：市街地農地。宅地比準方式（近傍宅地の1㎡単価−宅地造成費）×地積

市街化区域内の田畑は原則として「比準」で、農地としての固定資産税評価額ではなく宅地に準じた価額になるため、評価額が大きく跳ね上がります。4区分の詳しい違いは[農地の相続税評価は4区分](/articles/hyoka-nochi-kubun-takuchi-hijun/)で説明しています。宅地造成費の金額も同じ財産評価基準書に都道府県ごとに載っています。

## 山林・原野の記号

山林も同じ考え方で、「純」「中」は固定資産税評価額×倍率、「比準」は市街地山林として宅地比準方式で評価します。市街地山林は宅地への転用が難しい急傾斜地なら純山林として評価する取扱いがあり、原野・雑種地の扱いとあわせて[山林・原野・雑種地の評価](/articles/hyoka-sanrin-genya-zasshuchi/)にまとめています。

## 倍率を掛ける固定資産税評価額はどの年のものか

倍率を掛ける固定資産税評価額は、相続開始年の1月1日時点の価額（その年の課税明細書・評価証明書の「価格」）です。固定資産税の評価替えは3年ごとで、据え置きの年は前の基準年度の価額がそのまま続きます。倍率表も毎年改定されるため、必ず相続開始年の表と同じ年の固定資産税評価額の組み合わせで計算します。年をまたいで取った古い評価証明書を使うと数字が合いません。農地で住宅用地並みの減額がある課税標準額ではなく「価格」を使う点は宅地と同じです。

農地・山林は記号の読み違いで評価額が何倍も変わります。当センターでは倍率表の区分の判定から宅地造成費の計算まで対応しており、土地の評価は1か所110,000円（税込）から、相続税申告は基本報酬99,000円（税込・遺産総額4,000万円まで）から、初回相談は無料です。
