税務調査の当日は、調査官2名が自宅を訪れ、午前中は世間話のような質問が続きます。実はこの質問には**すべて意図があり、午後の通帳確認の前提を固めている**段階です。どんなことを聞かれ、どう答えればよいかを知っておくと、不用意な一言を避けられます。

## 午前中によくある質問とその意図

| 質問 | 聞いている意図 |
| --- | --- |
| 被相続人の出身地・学歴・職歴・退職金の額 | 生涯収入から見て申告された財産が少なすぎないか |
| 趣味や交友関係、よく行っていた場所 | ゴルフ会員権・書画骨董・多額の支出の有無 |
| 亡くなる前の健康状態、入院時期、介護の状況 | 亡くなる直前に本人が預金を動かせたか（誰が引き出したか） |
| 日常の財産管理は誰がしていたか、印鑑や通帳はどこにあるか | 名義預金の有無、家族が口座を管理していたか |
| 相続人の職業・収入、自宅の購入資金 | 相続人の資産が自分の収入で説明できるか |
| 貸金庫の有無、取引銀行、証券会社 | 申告書にない口座・財産の存在 |
| 生前贈与の有無、お金をあげた記憶 | 持ち戻し漏れ、贈与の実態 |

午後は、通帳のコピーを取りながら大きな出金の使途を1件ずつ尋ねられます。必要に応じて、相続人名義の通帳の提示や、貸金庫への同行を求められます。

## 答え方の基本

1. **事実だけを答える**。「たぶんこうだった」と推測で答えると、後で矛盾が生じたときに不利になります。覚えていなければ「確認して後日回答します」で構いません
2. **聞かれたことに答える**。聞かれていない財産や家族の事情を自分から広げないようにします
3. **資料を見ながら答える**。日付や金額は通帳や手帳で確認してから答えます
4. **税理士に確認する**。税法の判断に関わる質問（「これは贈与ですね？」など）は、その場で同意せず税理士に答えてもらいます

## やってはいけないこと

- 事実と違う説明をする、通帳や印鑑を隠す（重加算税の対象になり得ます）
- 調査官のメモや書類に、内容を確認しないまま署名する
- その場で「修正に応じます」と口頭で約束する

調査官は質問の答えを「質問応答記録書」にまとめ、署名を求めることがあります。内容が事実と違えば訂正を求め、納得できなければ署名を拒んでも問題ありません。当日は緊張しますが、誠実に、しかし慎重に答えることが結果を左右します。
