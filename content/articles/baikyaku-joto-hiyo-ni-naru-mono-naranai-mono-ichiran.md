相続した家を売ると、仲介手数料から解体費、相続登記の費用までいろいろな出費があります。どれを引けるかで税額は変わります。結論から書くと、**譲渡費用になるのは「売るために直接かかった費用」だけで、維持のための固定資産税や修繕費、相続税そのものは引けません。ただし相続登記の費用は譲渡費用ではなく取得費として引けます**。

## 譲渡費用になるもの

| 費用 | 補足 |
|---|---|
| 仲介手数料 | 売買価格の3%＋6万円（税別）が上限。領収書を保管 |
| 測量費・境界確定の費用 | 売るために行った測量に限る。相続税申告のためだけの測量は含まれない |
| 建物の解体費 | 更地にして売るために取り壊した場合。[解体費の扱い](/articles/fudosan-kaitai-hiyou-saimu-koujo-joto-hiyou/)参照 |
| 立退料 | 借家人に出ていってもらうために払ったもの |
| 売買契約書の印紙税 | 売主が負担した分 |
| 違約金 | 先の買主との契約を解除して、より有利な条件で売るために払ったもの |
| 売却のための広告費・鑑定料 | 売主が自分で依頼したもの |

## 譲渡費用にならないもの

| 費用 | 理由・扱い |
|---|---|
| 固定資産税・都市計画税 | 持っている間の維持費。売却時の日割り精算金は売却代金に含める |
| 修繕費・リフォーム代 | 維持管理の費用。ただし価値を高める改良工事は取得費に加算できる |
| 引越し費用・家財の処分費 | 売却に直接必要な費用ではない |
| 相続税 | 譲渡費用ではなく、[取得費加算の特例](/articles/shutokuhi-kasan-tokurei/)で取得費に足す別の制度 |
| 住宅ローンの繰上返済の手数料 | 借入の清算であり売却の費用ではない |
| 抵当権の抹消登記の費用 | 原則として譲渡費用にならない |

## 相続登記の費用は取得費になる

相続で取得した不動産の登録免許税や司法書士報酬は、所得税の取扱いで取得費に含めてよいことになっています。相続登記は義務化され、登録免許税の免税を受けられない場合は固定資産税評価額の0.4%がかかるため、評価額3,000万円の土地なら12万円です。相続税の申告書を作るときに払った税理士報酬は、相続税申告の費用であり取得費にも譲渡費用にもなりません。売却のためだけに依頼した費用（登記の名義整理のための調査など）は個別に判断します。

## 領収書は「誰が・何のために」で分ける

共有で相続した場合は、各人が自分の持分に応じて負担した費用を引きます。代表者がまとめて払った場合も、持分で按分して各自の申告に載せます。費用の領収書は、相続税の申告用（葬儀費用・債務）と譲渡所得用（売却の費用）を最初から分けて保管しておくと、確定申告の準備が楽になります。[売却前の相続登記の流れ](/articles/fudosan-baikyaku-mae-touki-nagare/)とあわせて確認してください。

当センターでは、相続税申告の段階で相続登記の費用や解体費の見積もりを把握し、売却後の譲渡所得の計算と確定申告まで一続きでお受けしています。相続税申告は基本報酬99,000円（税込・遺産総額4,000万円まで）から、初回のご相談は無料です。
