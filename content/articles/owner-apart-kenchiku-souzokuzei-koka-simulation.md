土地活用の提案書には「アパートを建てると相続税が◯◯万円下がります」と書かれています。その数字がどう出ているのかを、一つの例で最初から計算します。結論から書くと、**自用地1億円の土地に借入1億円で建てると、土地・建物・借入を合わせた課税対象は約2,000万円になり、建てる前の1億円から約8,000万円下がります**。ただし、改正と収支の両方を見なければ判断できません。

## 前提

- 土地：自用地評価1億円（路線価50万円×200㎡）、借地権割合60%
- 建築費：1億円（全額借入、団信なし）。完成後の固定資産税評価額は5,500万円（建築費の55%）
- 満室で賃貸中。他に預金1億円。相続人は子2人（配偶者なし）

## 建築前

遺産総額は土地1億円＋預金1億円＝2億円。基礎控除4,200万円を引いた課税遺産総額1億5,800万円を子2人で按分し、相続税の総額は**3,340万円**です。

## 建築後の評価

| 項目 | 計算 | 評価額 |
|---|---|---|
| 敷地（貸家建付地） | 1億円×（1−0.6×0.3） | 8,200万円 |
| 建物（貸家） | 5,500万円×（1−0.3） | 3,850万円 |
| 借入 | 債務控除 | −1億円 |
| 土地・建物・借入の合計 | | 2,050万円 |
| 預金 | | 1億円 |
| 遺産総額 | | 1億2,050万円 |

課税遺産総額7,850万円を子2人で按分すると、相続税の総額は**1,170万円**。建築前との差は**2,170万円**です。さらに[貸付事業用宅地の特例](/articles/kashitsuke-jigyo-takuchi-3nen/)で敷地200㎡が50%減額されれば、敷地は4,100万円になり、相続税は約460万円。差は約2,880万円まで広がります。

## 令和8年度改正で変わったこと

2027年1月1日以後に取得した貸付用不動産は、相続開始前5年以内であれば**時価の8割**で評価されます（[改正の内容](/articles/jiji-r8-kaisei-kashitsuke-fudosan-5nen-jika-8wari/)）。上の例で建築から5年以内に相続が起きると、建物の評価は3,850万円ではなく時価（建築費に近い額）の8割、たとえば8,000万円になり、課税対象は大きく戻ります。対策として成り立つのは、5年を超えて持ち続ける前提のときだけです。

## 数字の裏にある3つの確認点

1. **団信の有無**：団信付きなら借入は死亡で消え、[債務控除はできません](/articles/owner-apart-loan-saimu-kojo-soneki-bunki/)。上の例の借入1億円の控除がなくなります
2. **30年の収支**：家賃収入から返済・固定資産税・修繕・空室損を引いた累計がプラスか。相続税が2,000万円下がっても、30年の収支が赤字なら家族は得をしません
3. **預金の残り**：建築費を預金で払う場合は、債務控除がない代わりに預金が減ります。評価の下がり方は同じですが、納税資金が残るかを確認します

当センターは、ハウスメーカーや賃貸住宅の建設会社からの依頼で、オーナーの相続税試算と勉強会を行ってきました。建てる・建てない・売る・贈るを[同じ表で比べる](/articles/oya-no-tochi-uru-kasu-tateru-okuru-nokosu-hikaku/)ことから始めます。初回相談は無料です。
