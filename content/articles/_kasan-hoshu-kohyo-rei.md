相続税申告の見積もりで総額が大きく変わるのは、基本報酬よりも**加算報酬**の部分です。加算の対象と単位は事務所ごとに違うため、料金表の注記まで読む必要があります。ここでは、料金を公開している税理士事務所の例（各事務所の公式サイトの掲載内容、2026年10月7日に確認、事務所名の五十音順）で、加算の決め方を整理します。

## 土地の加算

土地は「1利用区分」「1利用単位」「1区画」ごとに数える例が多く見られます。同じ敷地でも、自宅と貸駐車場のように使い方が違えば別に数えます。倍率方式の土地を安くする例もあります。

| 事務所 | 土地の加算 |
|---|---|
| 円満相続税理士法人 | 5か所（利用区分）までは報酬に含む。超える場合は別途見積り |
| 角野真悟税理士事務所（豊中市） | 土地の数による加算なし |
| 神戸すえひろ税理士法人 | 原則1区画50,000円（税抜） |
| 相続専門オフィス（大阪市北区） | 1利用区分5万円、倍率方式は1万円（税抜） |
| 税理士法人チェスター | 1利用区分6.6万円（税込） |
| 税理士法人ブライト相続（豊中市） | 1利用区分6.6万円（税込） |
| VSG相続税理士法人 | 1利用区分5.5万円、倍率方式は1筆5,000円（税込） |
| 若狭税理士事務所（豊中市） | 路線価評価1利用単位5.5万円〜、倍率評価5,500円〜（税込） |

## 相続人の数の加算

相続人が2人以上のとき、基本報酬の10%を人数に応じて加える例が多く、上限を4人までとする例が見られます。

| 事務所 | 相続人の加算 |
|---|---|
| 円満相続税理士法人 | 相続人の数による加算なし |
| 角野真悟税理士事務所 | 相続人の数による加算なし |
| 神戸すえひろ税理士法人 | 1人増えるごとに基本料金の10% |
| 相続専門オフィス | 基本報酬×10%×（相続人の数−1） |
| 税理士法人チェスター | 基本報酬×10%×（相続人の数−1）、4人まで |
| 税理士法人ブライト相続 | 基本報酬×10%×（相続人の数−1）、4人まで |
| VSG相続税理士法人 | 2人目以降1人あたり10%、4人目まで |
| 若狭税理士事務所 | 3人以上の場合、1人増えるごとに10% |

## 非上場株式・期限直前・その他

- 非上場株式：1社15万円（相続専門オフィス・税抜）、1社16.5万円〜（チェスター・VSG・ブライト相続、税込）、原則100,000円（神戸すえひろ・税抜）、220,000円〜（角野真悟税理士事務所・税込）、別途見積り（円満相続）
- 期限が近い依頼：期限まで3か月以内は報酬総額の20〜50%を加算（チェスター）、基本報酬の30〜50%（ブライト相続）、報酬総額の20%（相続専門オフィス）、3か月を切ると特急料金がかかることがある（円満相続・角野真悟税理士事務所）
- 税務調査の立会い：日当55,000円（チェスター・円満相続・角野真悟税理士事務所、税込）、1日5万円（相続専門オフィス・相続税専門センター、税抜）
- 書面添付：一律55,000円（VSG・税込）、5万円（相続専門オフィス・税抜）、70,000円（神戸すえひろ・税抜）、0円（相続税専門センター）、報酬に含む（円満相続・角野真悟税理士事務所）、原則すべての案件に適用（チェスター）

## 見積もりで確かめること

1. 土地は何区分（何単位）と数えたか、倍率方式の土地の扱い
2. 相続人の加算は何人分か、上限はあるか
3. 期限までの日数による加算があるか
4. 税務調査の立会い、書面添付は含まれるか
