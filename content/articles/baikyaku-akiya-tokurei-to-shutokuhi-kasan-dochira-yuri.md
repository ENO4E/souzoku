「空き家特例も取得費加算も使えそうなのですが、両方使えますか」。答えは「どちらか一方」です。結論から書くと、**空き家特例（3,000万円控除）と取得費加算の特例は同じ不動産の売却には併用できず、取得費に加算できる相続税の額が控除額（3,000万円。相続人3人以上なら各2,000万円）より大きいときだけ取得費加算が有利になります**。相続税が少ない家では、ほとんどの場合、空き家特例を選ぶことになります。

## 要件の違い

| | 空き家特例 | 取得費加算 |
|---|---|---|
| 対象の家 | 昭和56年5月31日以前に建てられた家とその敷地 | 相続税の課税対象になった財産なら何でも |
| 亡くなった方の状況 | 相続開始直前に一人暮らし | 問わない |
| 相続後の利用 | 売るまで貸さない・住まない・事業に使わない | 問わない |
| 売却額 | 1億円以下（共有者の売却額を合計） | 制限なし |
| 期限 | 相続開始から3年目の年末まで、かつ2027年12月31日まで | 相続税の申告期限の翌日から3年以内 |
| 建物 | 耐震基準を満たすか取り壊す（2024年以降は買主が翌年2月15日までに行っても可） | 問わない |
| 効果 | 譲渡所得から最大3,000万円を控除 | 納めた相続税のうちその不動産の分を取得費に加算 |

## 計算例

亡くなった方が一人で住んでいた昭和50年築の家を、相続の翌年に3,000万円で売った場合です。取得費は不明で5%の150万円、譲渡費用は解体費と仲介手数料で250万円、譲渡所得は2,600万円です。

**例1：相続税が少ない場合**（納めた相続税100万円、このうち家と土地に対応する額60万円）
- 空き家特例：2,600万円−3,000万円→所得0、税額0円
- 取得費加算：2,600万円−60万円＝2,540万円×20.315%＝約516万円
- → 空き家特例が有利

**例2：相続税が多い場合**（遺産の大半が土地で、納めた相続税のうちこの土地に対応する額が3,500万円。売却額は9,000万円、取得費450万円、費用300万円、譲渡所得8,250万円）
- 空き家特例：8,250万円−3,000万円＝5,250万円×20.315%＝約1,066万円
- 取得費加算：8,250万円−3,500万円＝4,750万円×20.315%＝約965万円
- → 取得費加算が有利

取得費加算の額は、納めた相続税×（その不動産の相続税評価額÷その人の相続財産の課税価格）で決まります。土地が高く相続税を多く納めた人ほど加算額が大きくなります。[取得費加算の計算](/articles/shutokuhi-kasan-tokurei/)で確認できます。

## 判断の手順

1. 空き家特例の要件を満たすか確認する（[要件の詳細](/articles/akiya-tokurei-3000man/)）。満たさなければ取得費加算だけを検討する
2. 取得費に加算できる相続税の額を、相続税の申告書から計算する
3. 加算額が3,000万円（相続人3人以上なら各2,000万円）以下なら空き家特例、超えるなら取得費加算
4. 期限が近いほうを確認する。[売る時期の早見表](/articles/baikyaku-uru-jiki-de-kawaru-zei-hayami-3nen10kagetsu-akiya-choki/)参照

なお、居住用財産の3,000万円控除（相続人自身が住んでいた家）は取得費加算と併用できます。同居していた方は[こちらの記事](/articles/fudosan-douko-ie-baikyaku-3000man-koujo/)をご覧ください。

当センターでは、相続税申告の時点で「この家を売るならどちらの特例が有利か」を試算してお渡しし、売却後の確定申告もお受けしています。相続税申告は基本報酬99,000円（税込・遺産総額4,000万円まで）から、初回相談は無料です。
