親が認知症になり成年後見人がついた後で、「相続税対策として贈与や不動産の購入をしたい」と考えるご家族は少なくありません。しかし、**成年後見制度は本人の財産を守るための制度で、相続人のために財産を減らす行為は原則として認められません**。何ができて何ができないかを整理し、後見が始まる前にしておくべき準備を解説します。

## 後見人ができること・できないこと

| 行為 | 可否 |
| --- | --- |
| 本人の生活費・医療費・施設費の支払い | できる |
| 本人の預金管理、不要な契約の解約 | できる |
| 本人の生活のために必要な不動産の売却 | 居住用は家庭裁判所の許可を得て可能 |
| 子や孫への生前贈与 | 原則できない（本人の財産を減らす行為） |
| 相続税対策の不動産購入・生命保険の加入 | 原則できない |
| 遺言の作成 | 後見人は代筆できない。本人の判断能力が一時回復した場合に医師の立会いで可能 |
| 養子縁組 | 本人の意思が必要で、後見人が代わりに行えない |

後見人（親族でも専門職でも）は家庭裁判所の監督を受け、定期的に収支を報告します。本人の利益にならない支出は、後見人の責任問題になります。

## 後見制度支援信託とは

親族が後見人になる場合、家庭裁判所の判断で「後見制度支援信託」の利用を求められることがあります。本人の財産のうち、日常の生活費に必要な分だけを後見人の管理に残し、**残りを信託銀行に信託して、払戻しには家庭裁判所の指示書が必要**とする仕組みです。

信託した財産は本人のものであることに変わりなく、相続が開始すれば相続財産として相続税の対象になります。相続開始により信託は終了し、相続人が払戻しを受けます。相続税の申告では、信託銀行の残高証明で評価します。

## 後見が始まる前にできること

相続税対策は、本人に判断能力があるうちにしか行えません。

- 遺言の作成（公正証書遺言が確実）
- 暦年贈与や相続時精算課税を使った贈与の実行
- 家族信託の設定（後見と異なり、信託契約で財産の運用・処分の方針を決められる）
- 任意後見契約（本人が後見人と権限の範囲を決めておける）

家族信託と任意後見契約を組み合わせれば、判断能力が低下した後も、契約の範囲内で財産の活用を続けられます。ただし、家族信託でも「本人のため」という枠を超えた贈与は設計できません。

## 後見人がいる相続の申告

後見人がついていた親が亡くなると、後見は終了し、後見人は相続人に財産を引き継ぎます。後見人が家庭裁判所に提出していた財産目録と収支報告書は、相続財産の把握に非常に有用です。税務調査でも、後見開始後の資金の流れは明確なため、調査の焦点は後見開始前の贈与や預金の移動に向きやすくなります。
