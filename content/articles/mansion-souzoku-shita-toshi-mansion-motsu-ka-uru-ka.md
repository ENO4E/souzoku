相続した投資マンションを「とりあえず持っておく」と、修繕積立金の値上げや空室で負担だけが残ることがあります。結論から書くと、**年間の収支と修繕の見通しで持つ価値があるかを見て、売るなら取得費加算が使える相続開始から3年10か月以内に決める**のが判断の順番です。

## 1. 収支を数字にする

| 収入 | 支出 |
|---|---|
| 家賃（サブリースなら借上げ賃料） | 管理費・修繕積立金 |
| | 固定資産税・都市計画税 |
| | 管理委託料・保証会社の費用 |
| | 設備の修理・入れ替え、退去時の原状回復 |
| | ローンの返済（団信なしで引き継いだ場合） |

年間の手取りを出し、そこから所得税・住民税を引いたものが実際に残る額です。築20年を超えると修繕積立金が引き上げられ、給湯器やエアコンの交換が重なります。空室になれば家賃はゼロでも、管理費と修繕積立金は毎月出ていきます。

## 2. 築年数と大規模修繕

管理組合の長期修繕計画と修繕積立金の残高を確認します。積立金が計画より不足しているマンションでは一時金の徴収や積立金の大幅な値上げがあり、相続後の収支を変えます。総会の議事録と重要事項調査報告書（管理会社に請求）で、修繕の予定・積立金の残高・[滞納の有無](/articles/fudosan-mansion-kanrihi-tainou-shuzen-tsumitatekin/)が分かります。

## 3. 売るときの税金

- **取得費と取得日の引継ぎ**：譲渡所得は売却額−取得費−譲渡費用。取得費は被相続人が買った価額（建物は減価償却後）を引き継ぎ、分からなければ売却額の5%になります（[取得費の引継ぎと長期・短期の判定](/articles/fudosan-baikyaku-choki-tanki-shutokubi-hikitsugi/)）
- **長期・短期**：被相続人の取得日から数えて、売る年の1月1日で5年超なら長期（税率20.315%）、5年以下なら短期（39.63%）です。親が長く持っていた室なら、相続直後に売っても長期です
- **取得費加算**：相続税の申告期限から3年以内（相続開始から3年10か月以内）に売れば、その室に対応する相続税額を取得費に加算できます（[取得費加算の特例](/articles/shutokuhi-kasan-tokurei/)）
- 入居者がいるまま売る（オーナーチェンジ）と、空室にしてから売るのでは、買主の層と価格が変わります

## 4. 判断の順番

1. 相続税評価額と税額を確定する（区分所有補正で評価が上がっていないか）
2. 年間収支と修繕の見通しを出す
3. 時価の目安を複数の査定で把握し、売却した場合の手取り（譲渡所得税・仲介手数料・残債の返済後）を計算する
4. 持つ場合は管理組合・管理会社・金融機関の名義変更、売る場合は相続登記を済ませて3年10か月以内に売却する
5. 相続人が複数なら、共有で持たず、取得者を1人に決めるか売却代金で分ける（[換価分割の税務](/articles/fudosan-kanka-bunkatsu-baikyaku-eki-kakutei-shinkoku/)）

当センターでは、相続税の試算とあわせて、室ごとの収支と売却時の手取りを並べた「持つ・売る」の比較表をお作りしています。相続税申告は基本報酬99,000円（税込・遺産総額4,000万円まで）からで、初回相談は無料です。
