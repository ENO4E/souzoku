結論から書くと、**梅田から谷町線で1駅の南森町にある相続税申告相談センターは、相続税申告を基本報酬99,000円（税込・遺産総額4,000万円まで）からお受けしています。** 加算の単位もすべて公開しているので、ご自分の遺産で総額がいくらになるかを、相談の前に計算できます。初回の面談は0円で、ご契約まで費用はかかりません。

## 相続税申告の料金表（税込）

基本報酬は遺産の総額で決まります。

| 遺産の総額 | 基本報酬（税込） |
| --- | --- |
| 4,000万円まで | 99,000円 |
| 5,000万円まで | 170,500円 |
| 6,000万円まで | 242,000円 |
| 7,000万円まで | 308,000円 |
| 7,000万円超 | 個別にお見積り |

基本報酬には、申告書の作成、財産の評価、税額の計算、税務署への提出、必要書類のご案内が含まれます。財産の内容に応じて、次の加算がつきます。

| 加算の項目 | 料金（税込） |
| --- | --- |
| 土地の評価（1か所） | 110,000円〜 |
| 建物の評価 | 5,500円 |
| 上場株式・投資信託（1件） | 2,200円 |
| 非上場株式の評価（1社） | 110,000円〜 |
| 相続人が2人以上（2人目から1人） | 55,000円 |
| 書面添付（税理士法33条の2） | 88,000円 |
| 申告期限まで2か月未満の特急対応 | 基本報酬の125% |

## 遺産額別の総額例と、一般的な相場

加算まで全部足した総額で比べてください。一般的な相場は「遺産総額の0.5〜1%」とされています。

| 遺産と家族 | 当センターの総額（税込） | 一般的な相場 |
| --- | --- | --- |
| 預金と上場株式3銘柄で4,000万円・子2人 | 160,600円 | 20万〜40万円 |
| 自宅と預金で5,000万円・配偶者と子2人 | 396,000円 | 25万〜50万円 |
| 自宅と預金と上場株式5銘柄で7,000万円・配偶者と子2人 | 544,500円 | 35万〜70万円 |

料金表の見方で注意したいのは、「基本報酬＋遺産額の何%」という型です。基本報酬が安く見えても、遺産が増えると比例分が足されます。基本報酬が遺産額の段階で決まる型か、比例分が加わる型か、土地や相続人の加算があるかを確かめてから、同じ遺産で総額を出して比べてください。料金体系の型は[相続税申告の料金体系は4つ](/articles/zeirishi-hiyo-ryokin-taikei-4-kata-erabikata/)にまとめています。

## 格安でも省かないこと

安さの理由は、相続税申告に業務を絞り、書類の集め方から評価の手順までを決まった流れで進めていることです。工程は省きません。

- **土地の評価**：不整形地・私道・がけ地などの減額を、図面と資料で検討します。土地の評価が下がれば、相続税も下がります
- **書面添付制度**：税理士がどこをどう確認したかを書いた書面を申告書に添えます。税務調査の前に税理士が説明する機会があり、税務署に指摘されにくい申告になります
- **分け方と二次相続**：配偶者の税額軽減や小規模宅地等の特例を使える分け方を、次の相続まで含めて比べます

## 梅田から南森町へ。無料相談から申告まで

事務所は大阪市北区東天満の千代田ビル東館5階です。地下鉄谷町線・堺筋線の「南森町」駅、JR東西線の「大阪天満宮」駅からすぐで、東梅田から谷町線で1駅、北新地からJR東西線で1駅です。

1. **お問い合わせ**：お電話（06-6354-8220、平日9:00〜18:00）か、24時間受付の[お申込みフォーム](/contact/)から
2. **無料相談（約60分）**：来所かオンラインで。相続税がかかるか、税額の目安、費用の総額をその場でお伝えします。土日も予約でお受けします
3. **お見積り**：総額を書面でお渡しします。持ち帰ってご検討ください
4. **申告・手続き**：10か月の期限内に提出します。遺産分割や相続登記も、提携の司法書士・弁護士と同じ窓口で進めます

大阪梅田・南森町で相続税申告を格安で頼むなら、基本報酬だけでなく加算まで足した総額で比べてください。当センターは基本報酬99,000円（税込）からで、自宅と預金で5,000万円・配偶者と子2人なら総額396,000円が目安です。相続税がかかるかどうかは[相続税シミュレーション](/simulation/)で30秒で確かめられます。総額の例は[税理士費用の総額例](/articles/zeirishi-hiyo-souzokuzei-sogaku-rei/)にも載せています。
