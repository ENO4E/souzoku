相続税申告を税理士に依頼するとき、報酬の相場と内訳を知っておくと見積書を比較しやすくなります。また「払った報酬は相続財産から引けるのか」という質問も多いのですが、**税理士報酬は債務控除の対象にならず、所得税の必要経費にもなりません**。相場・内訳・税務上の扱いを整理します。

## 報酬の相場と内訳

相続税申告の報酬は、**遺産総額の0.5〜1%程度**が目安とされています。一般的な内訳は次のとおりです。

| 項目 | 内容 |
| --- | --- |
| 基本報酬 | 遺産総額（小規模宅地等の特例を使う前の価額が基準になることが多い）に応じた段階制 |
| 相続人加算 | 相続人が2人以上の場合、1人増えるごとに基本報酬の一定割合を加算 |
| 土地評価加算 | 土地1利用単位ごとに加算。不整形地や広い土地は上乗せされることがある |
| 非上場株式加算 | 自社株の評価が必要な場合、1社ごとに加算 |
| 書面添付 | 税理士法33条の2の書面を添付する場合の加算 |
| 期限加算 | 申告期限まで3か月を切った依頼などの割増 |
| その他 | 準確定申告、相続人の確定作業、現地調査の出張費、二次相続シミュレーション |

見積書では、**どの金額を基準に基本報酬が決まるか**（特例適用前か後か、債務控除前か後か）と、土地や株式の加算が何件分含まれているかを確認してください。報酬が極端に安い場合は、通帳の確認や名義預金の検討を省いていることもあり、調査のリスクと天秤にかける必要があります。

## 報酬の税務上の扱い

- **相続税の債務控除**：対象外。債務控除は相続開始時点で存在した被相続人の債務に限られ、相続開始後に相続人が負担する税理士報酬は含まれません。相続登記の費用や遺産分割の弁護士費用も同じです
- **所得税の必要経費**：原則として対象外。相続した賃貸不動産の不動産所得の計算でも、相続税申告の報酬は経費になりません
- **譲渡所得の取得費・譲渡費用**：相続した財産を売却したときの経費にもなりません

つまり、報酬は相続人の手取りから支払うものとして考える必要があります。

## 相続人間での分担

報酬は、依頼者（通常は代表相続人）が契約し支払いますが、申告は相続人全員の利益になるため、**取得財産の割合や税額の割合で分担する**取り決めが一般的です。遺産分割協議書に「相続手続きの費用は○○が取得する預金から支払う」と定めておくと、精算の手間と贈与の疑いを避けられます。
